# PulseGuard: Disease Prediction Web App

PulseGuard is a modern, AI-powered disease prediction web application. It provides users with early risk assessments for major diseases using machine learning models and a beautiful, glassmorphism-inspired UI.

## 🚀 Features
- **Landing Page**: Animated, glassmorphism design with parallax and floating hero section
- **Disease Cards**: Predict Diabetes, Heart Disease, Lung Cancer, and Stroke
- **Responsive**: Works on desktop, tablet, and mobile
- **Modern Animations**: Smooth fade-in, floating, and card slide-in effects
- **Accessible**: Keyboard navigation and focus styles
- **Custom Scrollbar**: Beautiful, modern look

## 🖥️ Tech Stack
- **Backend**: Flask (Python)
- **Frontend**: HTML5, CSS3 (glassmorphism, responsive), Font Awesome
- **ML Models**: scikit-learn, numpy, pandas

## ⚡ Quick Start
1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/pulseguard.git
   cd disease-prediction-final-main
   ```
2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```
3. **Run the app**
   ```bash
   python app.py
   ```
4. **Open in your browser**
   - Go to [http://localhost:5000](http://localhost:5000)
